# Images Directory

This directory contains placeholder images for the UTK Demo theme.

## Required Images

### Hero Section
- **hero-placeholder.jpg** (1700x700px)
  - Full-width hero background image
  - Should be impactful and represent the institution

### Content Sections
- **section-1.jpg** (800x600px)
  - Campus life / student experience image
  - Used in "Media & Text" section

- **section-2.jpg** (800x600px)
  - Research / academic image
  - Used in "Text & Media" section

### Logos
- **logo.svg** or **logo.png** (200px wide recommended)
  - Main logo for header
  - Should work on white background

- **logo-white.svg** or **logo-white.png** (200px wide recommended)
  - White version of logo for footer
  - Should work on dark background

### Theme Screenshot
- **screenshot.png** (1200x900px)
  - Screenshot of the theme for WordPress admin
  - Shows up in Appearance > Themes

## How to Add Images

1. Upload your images to this directory
2. Update the theme to use custom images via:
   - WordPress Customizer (Appearance > Customize)
   - Custom logo uploader (Appearance > Customize > Site Identity)
   - Or directly reference files in template files

## Placeholder Images

Until you add your own images, you can use placeholder services:

- https://placehold.co/800x600 (sections)
